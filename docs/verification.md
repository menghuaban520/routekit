# v0.1.0 验证记录

验证日期：2026-09-08。本记录只覆盖下列实际执行范围。

## 源码与浏览器

- Node 24，`npm run check`：TypeScript、58 项核心测试、Vite 生产构建通过。
- `npm run test:e2e -- --workers=3`：9 项 Chromium 回归通过。测试读取实际下载文件，并核对文件名、配置内容、JSON 往返和本地恢复，不以按钮反馈代替下载验收。
- 覆盖非法域名和章节注入、DNS 多行、无效 Hosts/CIDR/通用参数阻止导出、修正后恢复、同源多标签方案保存、切回新手模式保留高级规则、键盘标签切换及弹窗关闭后焦点恢复。
- 浏览器验证先使用 Codex 内置浏览器，再运行独立 Playwright CI 回归。375px 窄屏测试包含所有标签和长应用名；另目视检查 390px 手机页面与 1440px 桌面页面。
- 本地 Cloudflare 静态服务器验证正常运行没有控制台错误；主动外连测试被 CSP `connect-src 'none'` 阻止。该阻止为预期行为。
- 生产依赖 `npm audit --omit=dev --audit-level=high` 未报告漏洞。
