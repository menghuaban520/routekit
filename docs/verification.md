# v0.5.0 验证记录

本轮验证日期：2026-09-09。分别记录代码、浏览器、真实内核与生产站点证据。示例节点和受控响应不代表用户订阅的连接效果。

## 代码与交互

- Node 24，`npm run check`：TypeScript、9 个文件中的 281 项单元测试、Vite 生产构建通过。
- `python3 -m unittest discover -s tests/python`：44 项通过，包括节点检测器、实时监测器及本地任务接口。
- `npm run test:e2e -- --workers=3`：36 项 Chromium 回归通过。包含既有配置生成、节点绑定、方案保存、订阅用量、批量分流、主机查询与实时流量回归。
- 分类回归验证直达 URL、历史前进/后退、旧订阅锚点兼容、仅当前分类显示、手机切换及保留配置。侧栏切换会回到页面顶部；编辑器内部切换保留当前位置。开关维持 40 × 23 px，不受文本输入框高度影响。
- 订阅导入后连接身份相同的节点复用标识，自动检测的结果按身份回填。101 个节点拆成 100 + 1 串行执行；首批中断连接、后台完成后，重新连接能保留整体进度并继续剩余批次。
- 取消任务保留完成结果；重新导入改变连接身份后不会把旧检测误写入新节点。刷新后未知任务的结果单独展示。提交响应丢失时保留队列并要求明确重试，不自动关联一个无法确认身份的后台任务。
- 实时监测回归运行真正的 Python HTTP 服务和受控控制器，验证认证、启停和离页暂停。首次采样、会话变化、计数回退或中断后不生成虚假连接速率。
- 网络概览只检查当前出口和三次 HTTPS 延迟；下载测速另页启动。下载回归保留真实 HTTP 分块流读取、计时、取消、重试、错误及减少动态效果；完整接收 5 MB 后才生成均值，同时标明 Mbps 和 MB/s。
- Python 任务检查覆盖精确 Origin、Bearer 认证、方法与正文限制、单任务冲突、取消、终态前清理及接口兼容。修复测试导入产生的 Python 字节码缓存后，9 项监测器检查和生产构建再次通过；静态资产规则排除缓存文件。

## 真实 Mihomo 节点检测

本轮使用本机已安装的 Mihomo v1.19.25，启动隔离内核，通过临时认证 HTTP CONNECT 代理连接检测器限定的外部 HTTPS 目标。向真实本地助手提交一个受控节点任务，取得实际 HTTPS 延迟、公共出口 IP，并成功下载 125,000 字节及计算速度。共观察到 3 次经过认证的 CONNECT，未出现套接字错误。

任务进入完成状态前，隔离核心已经停止、临时配置已经清理。另一项取消实测验证：核心尚在运行时状态为 `cancelling`，清理结束后才变为 `cancelled`。测试进程和临时文件均已清理。

这证明新的任务接口能驱动真实代理内核和外网请求；没有使用私人订阅，没有修改用户的系统代理、既有客户端或小火箭配置，也不证明任意协议、服务商和地区的连通质量。

## 视觉与使用流程

沿用浅色蓝白界面，将导航拆为三组 14 个入口：网络概览、速度测试、主机查询、泄漏检查；导入订阅、套餐用量、节点列表、批量实测、实时流量；应用分流、连接设置、DNS 设置、链式代理、批量检查。桌面侧栏分组，手机先选择分组再显示其子项。

连接一次本地助手后，导入的节点可以自动排队实测，逐项回填、排序并用于分流。下载测速单独选择，默认关闭。原任务 JSON 下载/导入保留为折叠备用流程。配置及订阅状态在站内切换时保留；刷新网页会丢失尚未提交到助手的批次，界面有相应说明。

网络四个页面分别核对 1440、480、375 px，共 12 个实际浏览器状态，无横向溢出或运行时错误。最终生产构建截图：[网络概览](preview.png)、[手机网络页](preview-mobile.png)、[导入订阅](preview-import.png)、[节点列表](preview-subscriptions.png)、[应用与节点](preview-config.png)、[手机分流页](preview-config-mobile.png)。截图中的节点明确标为 example.com 示例，没有私人 IP、订阅、凭证或套餐数据。截图展示布局，不作为性能证据。

## 尚未验证的边界

- 尚未在用户目标 Shadowrocket 中实际导入、启用 `.conf` 并验证分流。部分协议须先导入配套节点并保留 `RK_` 名称，支持范围取决于客户端。
- 节点自动实测需要先运行本地助手和安装 Mihomo。网页本身不切换 SS / VLESS 等代理；实时流量桥接适用于 Mihomo / Clash Meta，小火箭的全设备流量仍在其客户端查看。
- DNS / WebRTC / IPv6 提供对照步骤与外部入口，不宣称“无泄漏”。DNS 加密、解析成功、打开检测页均不能证明无泄漏。
- 不同检测目标可能匹配不同分流规则；当前浏览器 IP 不能代表全部节点或应用的出口。位置、距离是近似值，住宅/机房等属性缺少证据时未知；未验证各中国大陆运营商的可达性。
- 订阅 URL 仍由浏览器直接请求；能否读取内容与用量头取决于服务商 CORS。套餐用量来自服务商快照，不能改变额度，实时计数不是账单。下载测速可能消耗套餐流量。
- Clash / Mihomo YAML、v2rayN 完整配置导出仍未实现。支持节点 URI 或使用 Mihomo 内核，不代表支持这些完整配置格式。
