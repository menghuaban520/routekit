## 能力边界

- Shadowrocket 字段曾对照官方 2.2.92（3445）安装包的默认配置核验；未导入或改变用户现有客户端配置，尚未完成用户目标设备的实际分流和 DNS 泄漏验收。
- DNS / WebRTC / IPv6 是外部检测入口，RouteKit 不保存或宣称其检测结论。加密 DNS 设置不能证明无泄漏。
- 网站 IP 只代表访问本站的一次请求；测速目标可能因域名分流走不同出口。每项数据有独立时间，IP 改变后清除旧测速结果。
- IP 地区与直线距离为数据库近似值，住宅/机房等属性无证据时显示未知。未测中国大陆各运营商的网站可达性。
- 订阅商是否允许 CORS、是否提供/暴露用量头，取决于订阅商。测试使用受控示例，未读取私人订阅；不可读取时使用本地文本导入，用量仍保持未知或由用户手动提供。
- 下载测速经过代理时可能消耗套餐流量。用量快照由服务商提供，本站不自行累计或改写套餐用量。
- Clash/Mihomo 与 v2rayN 的完整配置导出器仍是后续适配方向；支持它们使用的节点 URI 或借助 Mihomo 检测，不代表已支持其配置格式导入导出。
