## 独立 Mihomo 实测

使用本机已安装的 Mihomo v1.19.25 启动临时隔离内核，配置独立随机回环端口和随机控制器密钥。通过该内核向本地 HTTP 测试端点实际上传 81,920 字节并下载 163,840 字节。

新监测器真实读取 /traffic 和 /connections：总上下行速率出现非零值，活跃 DIRECT 链路计数增加，累计计数增加。最终内核计数为下载 164,069 字节、上传 82,156 字节（含协议开销）；结束后连接数为零。新会话首帧不生成虚假的连接速率。临时进程和目录已清理。

此项证明监测器能读取真实内核，不是用户节点测速。未修改用户运行中的 Shadowrocket、系统代理或既有客户端配置。原批量节点检测器的 v0.2 外网实测为 2026-09-08 历史证据，详见[检测器说明](probe.md)；本轮没有用私人订阅重复该实测。

## 尚未验证的边界

- 生成的 .conf 尚未在用户目标 Shadowrocket 中实际导入、启用及验证分流；没有改变用户现有连接。部分协议需先导入配套节点并保留 RK_ 名称，最终仍取决于目标客户端支持。
- 实时上下行桥接支持 Mihomo/Clash Meta。Shadowrocket 的流量与连接记录需要在小火箭客户端查看；网页不能读其所有应用流量。
- DNS / WebRTC / IPv6 提供检测教程及外部入口，不保存或宣称“无泄漏”。加密 DNS、解析成功和入口打开均不能证明无泄漏。
- 网站 IP、HTTPS 延迟和测速目标可能匹配不同分流规则，不能据此推断所有节点或应用的出口。IP 地区和距离是近似值，住宅/机房等属性无证据时未知；未测各中国大陆运营商可达性。
- 用量头是否可读由订阅商的 CORS 与响应头决定。网页刷新服务商快照，不能改变套餐限额，也不将实时流量计数当成账单。测速可能消耗套餐流量。
- Clash/Mihomo YAML 和 v2rayN 完整配置导出仍未实现。支持节点 URI 或使用 Mihomo 内核，不代表支持其完整配置格式。
